# 《沉默物语》· 困倦的跑

中文视觉小说游戏（Web · 纯前端，无需安装）。

> 跑步小组的四个人依次抵达各自的终点：A猝死、B降薪、C上岸——三个人的结局早已写好，
> 只有主角的结局握在你手里。时间从初三冲刺期，流到高考后的那个夏天。

## 在线游玩

GitHub Pages：`https://<你的用户名>.github.io/silent-story/`（推送后自动生效）

也可以直接下载 `index.html` 双击打开（需与 `立绘/` `背景PNG/` `音频/` `fonts/` 文件夹放在一起）。

## 内容

- 第一～六章 + 间章一/二，全篇连贯可玩（约 25–30 分钟）
- 三个小游戏：一日清单（第三章）· 金钱平衡（第四章）· 跑酷「跑出个明天」（第五章）
- 片段组装式结局：触发哪些片段，哪些就是你的结局；唯一有名字的结局是《真相的真心》
- 两首原创合成 BGM（lo-fi《打盹的跑道》/ 急促《争分夺秒》）
- 手绘蜡笔风立绘与程序化厚涂场景
